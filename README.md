# RUF-Q Modbus RTU 串口从站模拟器

这是一个基于 **Qt 6 Widgets + C++** 的 Windows 桌面模拟器，用于模拟 **RUF-Q 外夹式超声波流量计** 的 **Modbus RTU 从站（Slave）** 行为。

程序使用 `QSerialPort` 进行串口通信，**未依赖 Qt SerialBus**，而是自行实现了基础的 Modbus RTU 帧解析、CRC16、异常响应与寄存器访问逻辑。

---

## 1. 如何在 Qt Creator 打开

1. 安装 Qt 6（建议包含 `Qt Widgets` 和 `Qt SerialPort` 模块）。
2. 打开 Qt Creator。
3. 选择 **Open Project**。
4. 打开本项目根目录下的 `CMakeLists.txt`。
5. 选择合适的 Qt 6 Kit（Windows / MinGW 或 MSVC 均可）。
6. 配置后直接构建并运行。

---

## 2. 如何编译

### 方式一：Qt Creator
- 直接打开 `CMakeLists.txt` 后点击“构建”和“运行”。

### 方式二：命令行 CMake
```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="<你的Qt6安装路径>"
cmake --build build --config Release
```

Windows 示例：
```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.8.0/msvc2022_64"
cmake --build build --config Release
```

---

## 3. 如何运行

编译完成后运行生成的可执行文件：
- Qt Creator 中直接点击运行；或
- 在 `build` 目录中运行 `RufQModbusSlaveSimulator.exe`。

运行后：
1. 在串口配置区扫描并选择 COM 口。
2. 选择波特率、数据位、校验位、停止位。
3. 设置从站地址（Slave ID）。
4. 点击“打开串口”。
5. 使用主站软件发起 Modbus RTU 请求。

## 4. 如何用 Modbus Poll 测试

建议使用常见主站工具 **Modbus Poll**。

### 推荐测试参数
- 连接方式：Serial RTU
- 波特率：9600
- 数据位：8
- 校验位：None
- 停止位：1
- Slave ID：1

### 读取 holding register（功能码 03）
例如读取 `8192` 开始的 4 个寄存器：
- 地址：8192
- 数量：4
- 含义：
  - 8192~8193：瞬时流量（float）
  - 8194~8195：瞬时流速（float）

### 写单寄存器（功能码 06）
例如写入：
- 地址：8197（语言）
- 值：0 或 1

### 写多个寄存器（功能码 16 / 0x10）
例如写入 `8200` 开始的 2 个寄存器，用于设置“管道外径” float。

> 说明：float 采用 **两个 16-bit 寄存器，大端字序**。也就是高 16 位在前，低 16 位在后。

## 6. 已实现功能码

### 已完整实现
- `0x03` Read Holding Registers
- `0x06` Write Single Register
- `0x10` Write Multiple Registers

### 当前保留扩展架构
- `0x01` Read Coils
- `0x02` Read Discrete Inputs

当前版本中，`0x01/0x02` 仅保留了架构入口，收到请求时返回非法功能码异常，方便后续扩展。

## 8. 业务规则说明

1. `0x03` 返回当前 holding register 值。
2. `0x06` 仅允许写入定义为可写的 holding register。
3. `0x10` 支持写入连续寄存器，并校验数量与范围。
4. 当“累积量清零”寄存器（8320）被写为 `1` 时：
   - 自动将“上电累计”（8318~8319）置 0；
   - 然后将清零命令寄存器恢复为 `0`。
5. “瞬时流量”和“瞬时流速”默认不允许主站写入，但可以在 GUI 中手工修改，用于模拟设备运行过程。
6. 程序返回以下标准异常响应：
   - 非法功能码
   - 非法数据地址
   - 非法数据值

## 11. 关键实现假设

### 关于浮点数编码
本模拟器中的 float 统一按：
- 2 个 16-bit holding register
- **大端字序**
- 即高 16 位寄存器在前，低 16 位寄存器在后

### 关于序列号字段的文档歧义
需求文档一处写“共 6 字节”，另一处又描述为：
- 生产年份
- 生产周
- 产品型号
- 生产序列

这四个字段若都按 16-bit 映射，则总长度为 **8 字节**。为了便于 Modbus 寄存器建模，本模拟器按 **4 x 16-bit = 8 字节** 实现，并在代码中保留了明确注释。

### 关于 01 / 02 功能码和文档术语
需求中特别指出“系统状态位”写成“离散输入(01)”并不标准。标准 Modbus 术语应为：
- `01` = Read Coils
- `02` = Read Discrete Inputs

因此，本程序内部按**标准 Modbus 术语**设计数据模型与功能码保留接口。当前版本以 holding register 调试为主。
