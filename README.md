# RUF-Q Modbus RTU 串口从站模拟器

这是一个基于 **Qt 6 Widgets + C++** 的 Windows 桌面模拟器，用于模拟 **RUF-Q 外夹式超声波流量计** 的 **Modbus RTU 从站（Slave）** 行为。

程序使用 `QSerialPort` 进行串口通信，**未依赖 Qt SerialBus**，而是自行实现了基础的 Modbus RTU 帧解析、CRC16、异常响应与寄存器访问逻辑。

---

## 1. 如何在 Qt Creator 打开

1. 安装 Qt 6（建议包含 `Qt Widgets` 和 `Qt SerialPort` 模块）。
2. 打开 Qt Creator。
3. 选择 **Open Project**。
4. 打开本项目根目录下的 `CMakeLists.txt`。
5. 选择合适的 Qt 6 Kit（Windows / MinGW 或 MSVC 均可）。
6. 配置后直接构建并运行。

---

## 2. 如何编译

### 方式一：Qt Creator
- 直接打开 `CMakeLists.txt` 后点击“构建”和“运行”。

### 方式二：命令行 CMake
```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="<你的Qt6安装路径>"
cmake --build build --config Release
```

Windows 示例：
```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.8.0/msvc2022_64"
cmake --build build --config Release
```

---

## 3. 如何运行

编译完成后运行生成的可执行文件：
- Qt Creator 中直接点击运行；或
- 在 `build` 目录中运行 `RufQModbusSlaveSimulator.exe`。

运行后：
1. 在串口配置区扫描并选择 COM 口。
2. 选择波特率、数据位、校验位、停止位。
3. 设置从站地址（Slave ID）。
4. 点击“打开串口”。
5. 使用主站软件发起 Modbus RTU 请求。

---

## 4. 默认串口参数

- 波特率：9600
- 数据位：8
- 校验位：None
- 停止位：1
- 从站地址：1

---

## 5. 已实现功能码

### 已完整实现
- `0x03` Read Holding Registers
- `0x06` Write Single Register
- `0x10` Write Multiple Registers

### 当前保留扩展架构
- `0x01` Read Coils
- `0x02` Read Discrete Inputs

当前版本中，`0x01/0x02` 仅保留了架构入口，收到请求时返回非法功能码异常，方便后续扩展。

## 8. 如何用 Modbus Poll 验证新地址空间

建议使用常见主站工具 **Modbus Poll**。

### 连接参数
- 连接方式：Serial RTU
- 波特率：9600
- 数据位：8
- 校验位：None
- 停止位：1
- Slave ID：1

### 推荐验证步骤
1. 读取 `8192`，数量 `2`，应得到“瞬时流量”对应的两个寄存器。
2. 读取 `8194`，数量 `2`，应得到“瞬时流速”对应的两个寄存器。
3. 读取 `8221`，数量 `1`，默认应得到语言值 `1`（简体中文）。
4. 读取 `8222`，数量 `1`，默认应得到灵敏度值 `1`（中）。
5. 读取 `8223`，数量 `1`，默认应得到屏幕方向值 `0`（正向）。
6. 读取 `8215`，数量 `4`，应连续得到 `2026, 12, 1001, 1`。
7. 写入 `8222 = 2` 后，GUI 中“灵敏度”应刷新为“高”。
8. 写入 `8221 = 0` 后，GUI 中“语言”应刷新为 `English`。
9. 对 `8204` 开始写入 2 个寄存器，可整体修改“模拟上限” float。

> 说明：float 采用 **两个 16-bit holding register，低字寄存器在前，高字寄存器在后**。

## 9. 读写规则说明

1. `0x03` 返回最终版 holding register 当前值。
2. `0x06` 可写的 `u16` 项可直接写入。
3. `0x06` 对 float 双寄存器中的任意单个底层寄存器写入时，程序保持兼容，不会崩溃。
4. `0x10` 支持对 float 整块写入，也支持对 `8215~8218` 序列号连续写入。
5. “瞬时流量”和“瞬时流速”默认不允许主站写入，但可以在 GUI 中修改用于调试模拟。
6. GUI 修改后，主站重新读取会得到相同数据。

---

## 10. 关键实现说明

### 关于浮点数编码
本模拟器中的 float 统一按：
- 2 个 16-bit holding register
- **低字寄存器在前，高字寄存器在后**

### 关于 01 / 02 功能码和术语
标准 Modbus 术语应为：
- `01` = Read Coils
- `02` = Read Discrete Inputs

本程序内部按标准 Modbus 术语保留扩展接口，当前以 holding register 调试为主。
